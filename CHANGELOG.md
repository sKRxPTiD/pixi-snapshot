# Changelog

## 0.1.0 — 2026-10-25 — public preview

- Offline app inventory, source labels/URLs, installer package attribution, named profile, and setup notes.
- Optional Nova backup, wallpaper, and screenshots with persistent file selections.
- Assisted restore guide with missing apps and exact setup-file export.
- Local document-picker export and direct SFTP with strict known-host verification, progress, cancellation, separate server settings, and an unmetered queue.
- Pink/charcoal one-screen controls, PiXi fairy-dust wordmark, and ∅ Protocol branding.
- MIT source license, in-app privacy details, and bundled third-party notices.
- Bounded archive parsing, input validation, atomic local creation, and temporary-file upload.

Known limitations and exact validation coverage are in README.md and docs/VALIDATION.md. This preview does not automatically restore widgets, accounts, profiles, permissions, or private app data. F-Droid/Play listing and reproducible-build verification are future work.
